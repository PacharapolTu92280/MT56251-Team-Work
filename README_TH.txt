MT56251 Team Work Management - Fresh Start V1

1. แตกไฟล์ ZIP ลงในโฟลเดอร์ใหม่
2. เปิด index.html ด้วย Microsoft Edge
3. ครั้งแรกจะพบหน้าสร้าง Admin: กรอกชื่อ Username และ Password อย่างน้อย 8 ตัวอักษร
4. หลังสร้าง Admin จะเข้าสู่ Dashboard โดยอัตโนมัติ
5. เปิดแท็บ Admin เพื่อเพิ่ม Member หรือ Admin ร่วม และเปลี่ยนรหัสผ่านรายบุคคล
6. ใช้ Tasks เพื่อเพิ่มงาน, Calendar ดูวันครบกำหนด, Gantt ดูช่วงเวลางาน, Backup เพื่อ Export CSV/JSON
7. เก็บ JSON ที่ดาวน์โหลดไว้ใน OneDrive โฟลเดอร์ Backup data โดยจำกัดผู้เข้าถึง

ข้อจำกัดสำคัญ:
- เป็นเว็บ HTML ที่ทำงานในเครื่องและเก็บข้อมูลใน localStorage ของเบราว์เซอร์
- ไม่ได้เชื่อมต่อ OneDrive อัตโนมัติ และไม่ได้ซิงก์ข้อมูลระหว่างสมาชิก 20 คน
- ระบบ Login เป็นเพียงการแยกหน้าจอภายในเครื่อง ไม่ใช่การยืนยันตัวตนที่ปลอดภัย
- ห้ามนำข้อมูลบริษัทจริงหรือรหัสผ่านที่ใช้กับระบบอื่นมาใช้ในรุ่นนี้
- การเปิดไฟล์คนละตำแหน่ง/เบราว์เซอร์ อาจทำให้ข้อมูล localStorage แยกจากกัน
- ต้อง Backup JSON ก่อนล้างข้อมูลเว็บไซต์หรือย้ายเครื่อง
- ถ้าต้องการระบบใช้งานจริงแบบ 20 คนพร้อมกัน จำเป็นต้องมีระบบยืนยันตัวตนและที่เก็บข้อมูลส่วนกลางที่ได้รับอนุมัติ
